프로젝트명:아두이노 자율주행 RC카

제작기간:2026.05.04~05.23

사용 기술 및 하드웨어 Arduino IDE,아두이노 우노,DC 기어 모터 2개,초음파 센서, 모터 드라이버(L298N),배터리9v,1.5v
 
목적:아두이노와 초음파 센서를 활용하여 주변의 장애물을 감지하고, 장애물이 없는 방향으로 스스로 이동할 수 있는
자율주행 RC카를 제작함으로써 센서 기반 제어와 자율주행 원리를 이해하는 것을 목표로 하였다.

제작과정:이전에 제작한 아두이노 블루투스 RC카 프로젝트에서 얻은 경험을 바탕으로 모터 드라이버와 DC 기어 모터를 연결하고, 초음파 센서를 활용해 장애물과의 거리에 따라 
바퀴의 움직임이 달라지도록 코드를 구현하였다. 제작 과정에서는 기존의 2륜 구조와 달리 4개의 기어 모터를 동시에 구동해야 했기 때문에 기존 배터리만으로는 충분한 전력을 공급하기 어려웠으며, 
이에 따라 다양한 배터리 조합을 실험하여 4개의 바퀴를 안정적으로 구동할 수 있는 전압과 전류 조건을 새롭게 탐색하였다. 또한 하나의 서보 모터와 여러 기어 모터를 효율적으로 제어하기 위해 회로 배선을 다시 구성하였으며, 
초음파 센서의 감지 거리가 짧아 차량이 장애물에 반복적으로 걸리는 문제를 해결하기 위해 센서의 감지 거리를 조정하였다. 더불어 좌우 기어 모터의 회전 속도가 서로 달라 차량의 이동 방향이 틀어지는 현상이 발생하여, 
좌우 모터의 속도를 각각 다르게 설정하는 방식으로 주행 균형을 맞추었다. 이러한 시행착오와 문제 해결 과정을 거쳐, 최종적으로는 초음파 센서가 전방의 장애물을 감지하면 
RC카가 잠시 후진한 뒤 장애물이 없는 방향으로 스스로 이동하는 자율주행 RC카를 완성하였다.
